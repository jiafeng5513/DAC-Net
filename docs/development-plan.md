# DAC-Net 开发计划:深度学习波像差校正

> 面向 CSST 巡天望远镜 PSF 椭率测量的波像差补偿——从 NSGA-II 逐实例优化,演进为可**摊销**的深度学习求解器(DAC-Net,Deep Aberration Correction Network)。
> 本文基于"该问题是否适合深度学习"的评估结论,给出分阶段落地计划。

## 1. 背景与动机

- **现状**:补偿求解器以 NSGA-II 对每个实测 PSF 从零优化 32 个 Zernike 补偿系数(分钟级/实例)。合成协议下真解为 `x* = −ε`(测量误差取负),此时 merit ≈ 0、补偿后椭率精确等于真值。
- **痛点**:每个新样本都要重跑分钟级优化;批量 / 在线场景成本高。
- **目标**:训练一次、推理毫秒级的**摊销求解器**,在合成协议下达到论文指标(椭率测量误差 **< 0.01**),并保持可认证的计量精度。

## 2. 适用性结论(评估摘要)

**结论:适合,契合度高。** 主要理由:

1. 有**完美、可微、快速**的前向模拟器 → 可无限生成带**精确标签** `(PSF-M, x*=−ε)` 的训练对,无数据 / 标注瓶颈。
2. 本质是成熟方向"**深度学习波前传感 / 相位恢复**":PSF 图 → Zernike 系数回归。
3. 可微前向支持**物理(自监督)损失**,可反传过 FFT。
4. 输出低维、结构化(32 系数,或直接椭率)。
5. **摊销推理**带来数量级加速。

**关键难点与洞察:**

- **非唯一性**:`|FFT|²` 丢相位(孪生 `φ → −φ`,即 180° 旋转 PSF);准直器像差主导 PSF,望远镜分量被弱约束 → 纯系数 MSE 会在多解间"平均"。
- **洞察 A**:最终量是**椭率**,对 180° 孪生**不变** → 直接回归椭率比恢复全波前更适定。
- **洞察 B**:测量误差先验紧(ε 小、σ 逐阶已知,见 `DEFAULT_MEAS_SIGMA`)→ 把解限制在小-`x` 分支,显著缓解非唯一。
- **洞察 C**:可微前向 → 用物理损失 `‖PSF_S(f_θ) − PSF_M‖²` 替代 / 补充系数 MSE。
- **计量可信度**:学习模型误差难以先验界定 → 末端保留物理校验(混合方案)。

## 3. 技术路线(DAC-Net 架构)

- **可微前向**:将 `ForwardModel`(`|FFT{ mask · exp(i·2π·(base + Σ xₖZₖ)) }|²`)移植到 PyTorch,数值与现有 numpy 版交叉校验一致。
- **网络**:CNN 编码器(输入居中裁剪的 PSF-M,如 256×256)→ 回归头:
  - 头 A:32 个补偿系数 `x`;
  - 头 B:椭率 `(e, e1, e2)`(更适定,**推荐主目标**)。
- **损失(可组合)**:
  - `L_coef = ‖f_θ(PSF) − x*‖²`
  - `L_ellip = ‖(e1,e2)_pred − (e1,e2)*‖²`
  - `L_phys = ‖PSF_S(f_θ(PSF)) − PSF‖²`(自监督,过可微前向)
- **推理:混合方案**——网络出初值 `x₀`,再做 K 步物理梯度精修(可微 merit),兼顾速度与可认证精度("深度展开")。

## 4. 分阶段计划(里程碑与验收门)

按依赖顺序推进,每阶段设验收门;性能目标为验收标准而非排期。

### 阶段 0 — 梯度优化基线(去风险 + 先行价值)
- **目标**:利用可微前向,用 Adam / L-BFGS 直接最小化 merit,作为对照与"精度天花板"。当前 NSGA-II 把可微问题当黑盒,梯度法大概率又快又准。
- **任务**:实现 `baseline_grad.py`;在 seed=1 的 4 样本上对比 NSGA-II。
- **交付**:梯度基线求解器 + 对比结果。
- **验收**:单实例椭率误差 ≤ NSGA-II,且用时显著更短(目标秒级)。

### 阶段 1 — 可微前向 + 数据管线
- **目标**:PyTorch 前向 + 大规模数据生成。
- **任务**:`forward_torch.py`(与 numpy 版逐点校验,`max|Δ| < 1e-5`);`data.py` 复用 `rand_num` + 前向,批量生成 `(PSF-M, x*, 椭率*)`,支持存盘 / 在线生成。
- **交付**:可微前向模块 + 数据集生成器。
- **验收**:torch 与 numpy 前向 PSF 差异 `< 1e-5`;可按配置流式产出训练数据。

### 阶段 2 — 监督 CNN
- **目标**:PSF → 椭率(主)/ 系数(辅)回归。
- **任务**:`models.py`、`train.py`;训练 + 验证集评估。
- **交付**:基线网络 + 指标。
- **验收**:分布内测试集椭率误差均值 **< 0.01**(达论文指标),推理 `< 10 ms/样本`。

### 阶段 3 — 物理约束 / 自监督损失
- **目标**:引入 `L_phys` 缓解非唯一、减小系数偏置。
- **任务**:`losses.py` 组合;消融 `L_coef / L_ellip / L_phys`。
- **交付**:物理约束训练配置 + 消融表。
- **验收**:较阶段 2 在椭率误差或系数恢复上改善,预测稳定性提升。

### 阶段 4 — 混合推理(计量级)
- **目标**:网络初始化 + K 步梯度精修。
- **任务**:`infer.py`;扫描 K 的精度 / 耗时权衡。
- **交付**:混合求解器。
- **验收**:椭率误差达到或优于梯度基线,用时远小于纯优化;输出附末端物理 merit 校验值。

### 阶段 5 — 验证、鲁棒性与对比
- **目标**:系统评估与稳健性。
- **任务**:分布内 / 外(不同 RMS、σ、遮拦)评估;与 NSGA-II、梯度基线全面对比;`archived` 数据验证。
- **交付**:评估报告(纳入 `docs/`)。
- **验收**:达标项汇总;明确适用边界与再训练触发条件。

## 6. 评估指标

- 椭率误差 `|Δe|`(均值 / p95),硬指标 **< 0.01**。
- (可选)系数恢复 `‖x − x*‖`。
- 推理速度 `ms/样本` vs NSGA-II `分钟/样本`。
- 分布内 vs 分布外泛化差。
- 与梯度基线的精度差(判断 DL 的增量价值)。

## 7. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 相位恢复非唯一 | 主目标用椭率(孪生不变)+ 物理损失 + 紧先验 |
| 分布偏移 | 训练分布覆盖 + 在线梯度精修 + 明确再训练条件 |
| 计量可信度 | 混合方案末端物理 merit 校验;报告置信区间 |
| DL 增量价值不明 | 阶段 0 梯度基线做对照;若基线已达标,DL 定位为"加速器" |

## 8. 范围与非目标(初期)

- 聚焦**合成协议**(`demo` / `archived`);真实台架采集、硬件闭环暂不在范围。
- 复用现有 numpy 模拟器作为数据源与真值,**不改物理定义**。

## 9. 依赖

- 新增 **PyTorch**(CPU/GPU 均可;前向以 FFT 为主)。
- 复用现有 numpy / scipy 仿真做数据生成与交叉校验(见 `src/python/elli_error_generate/`)。
